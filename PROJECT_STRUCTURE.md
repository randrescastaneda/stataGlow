## Key Files by Purpose

### Configuration & Entry Points
- `package.json` - Extension metadata for VS Code
- `extension.js` - Extension activation
- `language-configuration.json` - Language config

### User Customization
- Settings in VS Code: `language-stata.*`
- Workspace file: `.vscode/stata-custom.json`
- Themes: `themes/stata-glow-*.json`

### Command Management
- Registry: `commands/official|ssc|github_*_commands.yaml`
- Schema: `commands/schema.json`
- Generator: `scripts/build-grammar.js`
- Validator: `scripts/validate-commands.js`

### Syntax Highlighting
- Grammar: `grammars/stata.json` (generated)
- Configuration: `lib/config-manager.js`
- Themes: `themes/stata-glow-*.json`

### Build & Development
- Build: `npm run build` → runs scripts/build-grammar.js
- Validate: `npm run validate` → runs scripts/validate-commands.js
- Test: `npm run test` → runs scripts/test.js

### Documentation
- Installation: `README.md`
- Contributing: `CONTRIBUTING.md`
- Changelog: `CHANGELOG.md`
- This guide: `IMPLEMENTATION_SUMMARY.md`

These files are **generated** by `npm run build` and should not be manually edited:

- `grammars/stata.json` - Generated from commands YAML

If you edit them manually, they will be overwritten on the next build.

## Customization Points for Users

### Settings File (`.vscode/settings.json`)
```json
{
  "language-stata.highlight.functions": true,
  "language-stata.highlight.macros": true,
  "language-stata.highlight.strings": true,
  "language-stata.highlight.regex": true,
  "language-stata.highlight.factorVariables": true,
  "language-stata.highlight.comments": true,
  "language-stata.enableCommunityCommands": true,
  "language-stata.customCommands": ["mycommand", "myanalysis"]
}
```

### Workspace Custom Commands (`.vscode/stata-custom.json`)
```json
{
  "commands": [
    { "name": "mycommand", "description": "..." },
    { "name": "myanalysis", "description": "..." }
  ]
}
```

### Theme Selection
Via VS Code: Ctrl+K Ctrl+T → Select "StataGlow Official" or "StataGlow Modern"
